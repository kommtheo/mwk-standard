## Requirements

- **Native fluency** in the target language
- **Technical comprehension** — you must be able to accurately render terms like "power asymmetry", "interaction architecture", "coercive marker", and "intent type" in your language
- Willingness to follow the MWK terminology conventions (see glossary in the Reference Summary)

---

## What contributors receive

- Named credit in the published translation (your name appears in the document)
- A printed copy of the book: *Dignity by Design* (Hartmut Kay Hirsch, Stuttgart, 2026)

---

## How to start

1. Open an Issue using the **Translation Request** template
2. State your target language and briefly confirm your background (native speaker + technical field)
3. A maintainer will confirm and assign the translation to you
4. Submit your translation as a Pull Request

**Filename convention:** `MWK_Reference_Summary_[LANG].md`  
Examples: `MWK_Reference_Summary_ZH.md`, `MWK_Reference_Summary_JA.md`, `MWK_Reference_Summary_ES.md`

Place your file in the `reference-summary/` directory.

## Terminology notes

The following terms have specific technical meanings in MWK and must not be softened or generalized in translation:

| English | Definition |
|---------|------------|
| Level 0 / Access | The permission question — "May I speak?" — mandatory first step |
| Level 1 / Offer | Named offer before execution — "Would you like me to...?" |
| Level 2 / Action | Execution of exactly what was authorized. No scope expansion. |
| Withdrawal | Complete disengagement after silence or rejection. No follow-up. |
| Coercive marker | Lexical pattern that removes perceived choice ("must", "but") |
| Evaluative language | Statements judging the user — filtered in Module 2 |
| Power asymmetry | Structural imbalance where one party controls more |
| Self-determination | The user's right to decide — structurally preserved, not verbally acknowledged |
